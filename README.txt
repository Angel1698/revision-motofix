Página de revisión de Motofix para Coordinación (versión de prueba con datos de octubre 2026).
Cómo publicarla en GitHub Pages:
1. Crea un repositorio nuevo en GitHub, por ejemplo revision-motofix.
2. Copia esta carpeta completa (index.html, datos.js, img e imgn) al repositorio y haz Commit y Push en GitHub Desktop.
3. En GitHub: Settings > Pages > Branch: main, carpeta / (root) > Save.
4. Para un subdominio (ej. revision.motofix.com.mx): en Settings > Pages escribe el dominio en Custom domain, y en GoDaddy agrega un registro CNAME 'revision' que apunte a angel1698.github.io (igual que acomodo.motofix.com.mx).
Fuera de Claude los comentarios se guardan en el navegador de quien revisa; el botón 'Copiar todos mis comentarios' los copia para mandarlos por WhatsApp.
